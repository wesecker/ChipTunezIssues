# ChipTunez Issues

This is the public issue tracker for ChipTunez, an Android app for playing module and chiptune music. The app's source code is in a separate private repository.

[Open a new issue](https://github.com/wesecker/ChipTunezIssues/issues/new) to report a bug or suggest an improvement. Please search [existing issues](https://github.com/wesecker/ChipTunezIssues/issues) first.

For a bug report, please include:

- Your ChipTunez version, Android version, and device model
- The steps needed to reproduce the problem
- What you expected to happen and what happened instead
- The music format or file type involved, if relevant
- A screenshot or log if it helps explain the problem

Please remove personal information from screenshots and logs. Only share music files that you have permission to share.

For an improvement request, describe the behavior you want and how it would help you use the app.
